# 编辑页字段顺序调整

## Goal

客户管理编辑页字段位置调整：消费等级移到合作状态下方；首次回款时间和接入时间移到运营经理下方。

## Background（已确认事实，来源：代码探索）

- 编辑页 `frontend/src/views/customers/detail/EditCustomerDialog.vue` 为三列 grid 布局：
  - 列二「结算配置」当前顺序：结算方式 → 结算周期 → 价格策略 → ERP系统 → 合作状态 → 启用结算 → 自动发起结算 → **消费等级**（128 行）
  - 列三「人员与状态」当前顺序：商务经理 → 运营经理 → 是否重点客户 → 是否停用 → **首次回款时间** → **接入时间**
- 目标：
  - 消费等级移到「合作状态」正下方（启用结算之前）
  - 首次回款时间、接入时间移到「运营经理」正下方（是否重点客户之前）

## Requirements

- R1 列二「结算配置」字段顺序调整为：结算方式 → 结算周期 → 价格策略 → ERP系统 → 合作状态 → **消费等级** → 启用结算 → 自动发起结算
- R2 列三「人员与状态」字段顺序调整为：商务经理 → 运营经理 → **首次回款时间** → **接入时间** → 是否重点客户 → 是否停用

## Acceptance Criteria

- [ ] AC1 编辑页结算配置列消费等级位于合作状态与启用结算之间
- [ ] AC2 编辑页人员与状态列首次回款时间、接入时间位于运营经理与是否重点客户之间
- [ ] AC3 字段绑定、校验、提交流程不变，仅模板顺序变化

## Out of Scope

- 修改字段内容、绑定、校验规则
- 调整其他列（客户标识列）顺序

## Key Decisions

- 仅调整模板中 `<a-form-item>` 块的相对顺序，不动数据逻辑
