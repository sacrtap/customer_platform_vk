# PRD：客户新增「自动发起结算」属性

- 日期：2026-09-29
- 分支：`feat/customer-auto-initiate-settlement`

## 需求

1. 客户管理页「新增客户」「编辑客户」中新增客户属性「自动发起结算」，取值为是/否，**默认是**。
2. 客户列表筛选项新增「自动发起结算」，选项为全部/是/否，**默认全部**。

## 字段命名

`customers.auto_initiate_settlement`（Boolean, nullable=True, default=True）

- 与 `is_settlement_enabled`（是否启用结算）语义区分：前者控制「结算是否自动发起」，后者控制「是否参与结算」。
- NULL 语义：历史新增列后为 NULL，视为「是」（与模型默认值一致）。

## 验收标准

- [ ] AC1 新建客户时不填该字段 → 落库为 `true`；显式填 false → 落库为 false。
- [ ] AC2 编辑客户可修改该字段并持久化，详情接口返回该字段。
- [ ] AC3 列表筛选「是」返回 `true` 与历史 NULL 客户；「否」仅返回严格 `false` 客户（不含 NULL）。
- [ ] AC4 前端「新增客户」表单默认选中「是」；「编辑客户」回填已有值。
- [ ] AC5 批量编辑支持该字段（可选加分项，已实现）。
- [ ] AC6 后端单测/集成测试全绿，前端 `vue-tsc` 0 error、`vite build` 通过。

## 范围边界

- 不涉及 Excel 导入/导出模板（导入未填该列时由模型默认值兜底为 true；导出列超出模板列不影响既有测试）。
- 不涉及结算引擎运行逻辑（仅客户属性存储与展示），「自动发起结算」后续由结算任务消费。
