# VR结算模块三项优化与权限可见性修复

## Goal

用户反馈三项：1) 创建结算单弹框增加备注说明字段（多行文本）；2) 设置减免按钮移出列表操作列；3) 客服主管分配 VR 权限后看不到功能模块。

## Requirements

- R1 创建弹窗提供「备注说明」选填多行输入，提交后落库并在详情可见
- R2 「设置/修改减免」入口从列表操作列移除；详情抽屉保留同功能入口，前三态可见规则不变
- R3 仅持 `vr_settlement:view`（无 `billing:view`）的角色必须能看到「结算管理」组与 VR 菜单项

## Acceptance Criteria

- [x] AC1 创建弹窗含「备注说明」textarea（选填、多行、字数上限），提交后详情抽屉展示且保留换行
- [x] AC2 列表操作列无「设置减免/修改减免」按钮；详情抽屉前三态仍有「设置减免」按钮
- [x] AC3 模拟客服主管视角（roles=客服主管 + 真实权限集）：侧边栏「结算管理」父组渲染，子菜单仅 VR 项可见
- [x] AC4 集成测试覆盖多行备注创建→详情/列表回显、不传为 None；后端全量 1482 passed；vue-tsc/build 通过

## Notes

- 根因（R3）：AppSidebar「结算管理」父组 `v-if="can('billing:view')"`，客服主管角色无该码 → 整组被埋；子项各自的 `can('vr_settlement:view')` 再对也看不到
- 验收方式：浏览器实测（多行输入、抽屉 pre-wrap 计算样式、操作列按钮集、localStorage 模拟非超管视角）
- 提交：feat 备注字段（8 文件）+ fix 减免入口/权限可见性（2 文件）
