# 错误码说明

当请求失败时，响应体中的 `code` 字段为非零值，`message` 字段描述具体错误原因。

## 错误码结构

错误码为 5 位数字，按大类划分：

- **第 1 位**：错误大类（`4` = 客户端错误，`5` = 服务器错误）
- **第 2-3 位**：错误小类（`00` = 通用，`01` = 参数，`02` = 格式，`03` = 认证，`04` = 权限，`05` = 资源不存在）
- **第 4-5 位**：具体错误序号

## 错误码对照表

### 成功

| 错误码 | 含义 | HTTP 状态 |
| --- | --- | --- |
| `0` | 成功 | 200 |

### 客户端错误

| 错误码 | 含义 | HTTP 状态 |
| --- | --- | --- |
| `40001` | 通用参数错误 | 400 |
| `40002` | 格式错误（邮箱、手机号等） | 400 |
| `40003` | 文件格式错误 | 400 |
| `40004` | 缺少必要参数 | 400 |

### 认证错误

| 错误码 | 含义 | HTTP 状态 |
| --- | --- | --- |
| `40101` | 未认证 / 缺少 Token | 401 |
| `40102` | Token 无效或已过期 | 401 |
| `40103` | Token 已失效（黑名单） | 401 |
| `40104` | API-Key 无效或已停用 | 401 |
| `40105` | API-Key 已过期 | 401 |

### 权限与资源

| 错误码 | 含义 | HTTP 状态 |
| --- | --- | --- |
| `40301` | 权限不足 | 403 |
| `40401` | 资源不存在 | 404 |

### 服务器错误

| 错误码 | 含义 | HTTP 状态 |
| --- | --- | --- |
| `50000` | 服务器内部错误 | 500 |
| `50001` | 服务处理失败 | 500 |
| `50002` | API-Key 创建失败 | 500 |

## 错误响应示例

```json
{
  "code": 40004,
  "message": "缺少必要参数: erp_channel"
}
```
