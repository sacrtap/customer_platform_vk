# 变更日志

开放平台文档站与 API 变更记录，按时间倒序排列。

## 2026-10-10 — 新增全量客户余额接口

- 新增 `GET /api/v1/balances`：返回全部有效客户（不限 ERP 渠道，含无 ERP / noerp 客户）的客户 ID、名称与当前余额，与渠道版接口响应结构一致。

## 2026-09-19 — 文档站上线

- 基于 VitePress 搭建开放平台开发者文档站，替换原前端 SPA 手写指南页。
- 文档结构：指南（快速开始 / 认证 / 错误码）+ API 参考（接口索引 / ERP 渠道客户余额查询）。
- 认证说明围绕「系统管理 → API-Key 管理」展开：获取、传递、状态、安全注意事项。
